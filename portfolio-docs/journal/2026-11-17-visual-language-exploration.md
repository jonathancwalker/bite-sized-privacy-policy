# Homepage visual language exploration

The user said the current serif headline and off-white background feel “very AI-esque.” They asked for three to five named visual directions that follow from the project's mission, plus a component that lets them see the homepage in each style before choosing one to develop. Source: current project conversation, November 17, 2026.

The starting point is the [focused entry mock](../assets/exports/2026-11-17-entry-home-clean.jpg): structurally simpler, but still using the serif/off-white treatment the user now rejects. This exploration is intentionally about homepage visual language. The connected intake, claim, and report flow remain available separately while a direction is chosen.

Codex built a [local concept gallery](../../app/concepts.html) with four switchable, visual-only homepage studies. Each explores a mission emphasis rather than just a palette: **Open File** makes terms inspectable through a numbered reference layout; **Spotlight** emphasizes agency through high-contrast focus; **Margin Notes** shows exact source beside an illustrative plain-language reading; **Plain Talk** lowers intimidation with a direct conversational tone. Each study names its visual ingredients and a potential tension. These are proposals, not a user-selected direction. See [D08](../decisions.md#d08--explore-mission-led-homepage-voices).

A read-only design critique found distinct directions but corrected acceptance-sounding copy, an illustrative paraphrase that initially dropped a time limit and legal exception, low-contrast small labels, and keyboard access. The final local browser pass captured all four desktop studies, checked a 390-pixel viewport without horizontal overflow, verified arrow-key switching and the jump-to-mock control, and verified the gallery's link to the working flow. The critic observed that Open File best preserves the earlier three-starter hierarchy; the other directions give more room to the hero, which is a tradeoff for user review.
